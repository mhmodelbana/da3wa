# Da3wa Multi-Invitation

هذه النسخة تحول الدعوة من ملف ثابت إلى نظام Multi-Invitation يعمل مع Supabase.

## المزايا
- صفحة دعوة واحدة `index.html` تقرأ الدعوة من خلال الـslug.
- لوحة إدارة `admin.html`.
- إنشاء دعوات متعددة لكل واحدة رابط مستقل.
- تعديل المحتوى بدون لمس الكود.
- نشر / إخفاء الدعوة.
- نسخ دعوة موجودة.
- حذف دعوة.
- تسجيل دخول Supabase Auth.
- RLS: كل مدير يدير دعواته فقط، والزائر يقرأ الدعوات المنشورة فقط.

## الخطوات
1. في Supabase افتح SQL Editor وشغّل `supabase-schema.sql`.
2. اترك `supabase-config.js` بالمفتاح Publishable فقط. لا تضع Secret/Service-Role Key في GitHub.
3. ارفع الملفات إلى مستودع GitHub نفسه.
4. افتح `admin.html` وأنشئ حساب المدير مرة واحدة.
5. اضغط `+ دعوة جديدة`؛ سيبدأ المحرر من بيانات `default-invitation.json`.
6. اكتب Slug مثل `ammar-fatma` ثم احفظ.
7. افتح رابط الدعوة من زر المعاينة.

## روابط الدعوات
النظام يدعم:
- `/ammar-fatma`
- `/ahmed-mona`
- `/mohamed-sara`

وعند استضافة static بدون rewrites يمكن استخدام fallback:
- `/?invite=ammar-fatma`

يوجد `404.html` لمحاولة تشغيل المسارات النظيفة على الاستضافات التي تمرر 404 إلى الصفحة المخصصة.

## ملاحظة مهمة عن المفتاح السري
لا تستخدم مفتاح Supabase Secret داخل أي ملف frontend أو GitHub. إذا تم كشفه، قم بتدويره/إلغائه من Supabase قبل النشر.

## الموسيقى
ملف `music.mp3` ليس مرفقًا داخل هذه الحزمة؛ احتفظ بملف الموسيقى الموجود عندك في نفس مجلد الموقع أو غيّر رابط الموسيقى من لوحة التحكم.
